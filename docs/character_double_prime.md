```
T_{A⊗B} ℭ  ⊋  T_A ℭ ⊕ T_B ℭ.
```

The excess directions are emergence, *quantitatively*. The two bits lift again, with

A path `ℭ_n → ℭ_{n+1} → …` through strata. Each up-step *may* add a protected bit — but

## The marginal point = non-convergence

`ε → 1` is where the inductive limit of `{ℭ_n}` fails to converge — the closure cascade

## Isolation, lifted

At this level the boundary is **dis-emergence**: `⊗` degenerating to the trivial map, the

attained).

## Measurement discipline′′ — the kills

Emergence-as-honorific is unfalsifiable; emergence-as-closure-non-additivity is not.

1. **Unprotected excess.** A coupling-minted current whose chirality is removable by smooth
   deformation *while the frustrated triad persists* → protection is not inherited from the
   graph, the binding has no teeth, and the layer reduces to "coupling adds structure" (true
   but empty). *This is the load-bearing kill — it sits on the open question.*
2. **Unmechanized excess.** A minted protected bit with **no** union-graph frustration
   behind it → B3 is not the mechanism → the proposal is false (emergence is real but not
   what character′′ says it is).
3. **Meta (inherited).** Stall (the strata stop being populated by real substrates) or
   float (a bespoke node never receipts) — the generative-metaphor kills from
   `character_prime`.
