# Translation worked example — "continuous-amplitude autonomy"

**What this is.** The six-step inbound translation (`framework/translating_FDR_steps.md`, detailed in
`framework/character_fdr_treatment.md`) applied to the object **continuous-amplitude autonomy** — a collective
amplitude coordinate possessing its *own* sustained self-gain, `Ẋ = a_eff·X + bX³ + …` with `Re(a_eff)>0`,
surviving removal of external drive. This is the quantity the cascade thread (`frustration_ascent_cascade_handoff.md`)
found could only ever be *inserted* (2A μ, 2B G_SELF, transduction-wall, `a_eff = μ+2κ` δ-independent). The
session stated the verdict via the mpa-legal rule ("a character coefficient may not be a constant"). **The
translation re-derives the same verdict from inside the two-frame FDR structure — without the legal rule as an
external axiom.** Provenance: **[est.]** literature (→ `pa:` key), **[MPA]** framework's own binding.

**Step 1 — deep commonality.** Strip the substrate: what stochastic-process relation is "amplitude autonomy"?
It is a statement about the **amplitude face** of the Boolean→MPA deformation read as fluctuation–response.
That face is, by the framework's own assignment (`character_fdr_treatment.md` §5): *chit/D drives c→s→r; observables
α_s, P_s; the **external frame** (amplitude×h)→X.* "Autonomy" = the response carries a **self-sustaining (gain)
component**: not `R(t,t')=(X/T)∂_{t'}C·θ` relaxing back (X≡1, purely restoring), but a positive growth rate in
the amplitude register. So the object is: *a sustained `Re(a_eff)>0` living in the external/amplitude frame.* **[est.** FDR object; **MPA** assignment]

**Step 2 — audit hidden assumptions.** The gain is `a_eff = μ + 2κ` (ring; Fruchart chiral phase `= μ`).
Silently it carries: **time-translation invariance** (a constant, not a function of any NESS quantity);
**reference to an external baseline** (μ = per-unit pump, κ = coupling — both supplied from outside the
circulation, the FDR analogue of fixed bath `T`). The tell is exactly Step-2's equilibrium baseline +
fixed-T assumptions: the amplitude gain is pinned to an *external constant*, never to the violation factor X.
**[est.** assumptions; **MPA** audit]

**Step 3 — filter into buckets (the decisive step).** The character filter: *objects exist only during
sustained NESS traversal; the self-probe is **defined iff a current exists**.* The two-frame definedness
asymmetry (`character_fdr_treatment.md` §4) is the sieve:

| frame | reference | definedness |
|---|---|---|
| **external / amplitude** | needs an *external* probe / baseline (T_sub, the pump) | defined wherever a probe couples — **not intrinsic** |
| **self-probe / sign-topological** | the system's own circulation **is** the reference (`pa:tur`) | defined **iff** J≠0 — **intrinsic** |

Autonomy requires the gain to be **self-sourced** (that is what "its own" means). But the only **intrinsic**
(self-referenced) frame is the self-probe = affinity 𝒜 = the sign-topological face. The amplitude/external
frame is *substrate-conditional* — its reference is always external. ⇒ **A self-sourced amplitude gain is a
"no-transfer" item**: the amplitude face has no intrinsic referent, so its gain can only ever be referenced to
an external constant. *Filter verdict:* amplitude **magnitude** transfers (it is the extensive J_ss, §5 — it
flows with chit); amplitude **gain/autonomy** does **not** transfer as an intrinsic quantity. **[MPA sort]**

**Step 4 — replacement for the no-transfer item.** The FDR Step-4 move is `T→T_sub`, `X→X(t,t',τ_obs)` — make
the external baseline *flow*. Pressed onto amplitude autonomy, the affinity-vs-magnitude split (§5) supplies
the only legal flowing object: **𝒜** is intensive, drive-independent, **topology-forced** — it *flows with the
NESS*; **J_ss** is extensive, scales with rates, flows with chit. So what can be made to flow is the current
**magnitude** (a state riding on chit) and the **chirality/affinity** (the sign-topological face). The **gain
coefficient** — the Re eigenvalue, the rate of self-amplification — is neither: it stays the external constant
μ+2κ. **Replacement verdict:** autonomy that flows = chirality/handedness/topology (𝒜); autonomy of the
amplitude *gain* has no flowing replacement. **[MPA]**

**Step 5 — import established machinery.** Harada–Sasa (`pa:harada-sasa`): the bridge is
$$V_{\text{ext}}=\langle\sigma\rangle=J\cdot\mathcal{A}.$$
Read what sits in the dissipation that *defines* the NESS register's always-on cost: **current × affinity**.
J (magnitude, flows) × 𝒜 (the **sign-topological face**). **There is no amplitude-gain term in the dissipation
identity at all.** The heat-tax that a genuine NESS register must pay is carried entirely by J·𝒜 — the
topological face. An amplitude self-gain `Re(a_eff)` appears nowhere in ⟨σ⟩, so it is not part of what the
circulation self-sustains. **[est.** Harada–Sasa, Schnakenberg; **MPA** reading]

**Step 6 — verify integration.** chit grounding (`pa:crooks-ft`): $\text{chit}=\ln(G_0/L)=\langle\sigma\rangle_{\text{event}}$,
and one ch (≡ln2 nats) of headroom is one bit of held character — *on the thermo face*. Since the chit runs
through J·𝒜, the **held character is the affinity/topological face**. Continuous-amplitude autonomy, carrying
no 𝒜 component, holds **zero ch** — it is not measured in the framework's character quantum. It integrates as
the X≡1-adjacent degeneracy: a Re coefficient that, like equilibrium `T`, is a constant external reference, not
a character-bearing register. **Integration verdict: amplitude autonomy does not close as a character object;
chirality does.** **[MPA]**

## Result

The translation lands the session's verdict **from inside the FDR two-frame structure**:

- The **amplitude/external frame** is the *substrate-conditional* one — its reference is always external, so an
  amplitude self-gain is necessarily pinned to an external constant (the pump μ / coupling κ). It is the FDR
  analogue of fixed bath `T`. **This is *why* `a_eff = μ+2κ` is a constant — not a coincidence of one model,
  but the frame the quantity lives in.**
- The **self-probe / sign-topological frame** is the *intrinsic* one (defined iff J≠0). Only it carries a
  self-sourced, flowing quantity — the affinity 𝒜 (chirality/handedness/topology).
- The dissipation identity ⟨σ⟩ = J·𝒜 and the chit grounding both run through the topological face, so **held
  character lives there and only there.** Amplitude autonomy holds zero ch.

So **continuous-amplitude autonomy = generative-on the external/amplitude face = supplied-not-minted**, while
**chirality/topology = generative on the intrinsic self-probe face = legally flows with the NESS.** This is the
cascade verdict (generative-of-organization/chirality, parasitic-on-drive) **derived**, not asserted: the
mpa-legal "no constant" rule is recovered as a *theorem of the two-frame definedness asymmetry* — a character
self-gain must be intrinsic; the only intrinsic frame carries 𝒜, not amplitude; therefore amplitude gain is
external/constant of necessity. (Same shape as the Central Commitment being the falsifiable direction of the
iff-chain rather than an axiom, `character_fdr_treatment.md` §4.)

**What MPA owns here (residual rule).** Imports re-read: the FDR object, two-frame definedness asymmetry,
Harada–Sasa bridge, Schnakenberg/chit grounding (all existing `pa:` keys). MPA's binding = the **identification
`amplitude-autonomy ↔ external frame ↔ external-constant gain`**, i.e. that "autonomy must be intrinsic" + "the
only intrinsic frame is the self-probe (𝒜)" *forces* amplitude gain to be supplied. Over-determination check
(transport-method Step 2/3): the result is checkable because it is read in ≥2 registers that the sources never
tied — the spectral fact (`a_eff` δ-independent, `a_eff_reduction.py`), the dissipation identity (⟨σ⟩=J·𝒜, no
amplitude term), and the chit grounding (held character = 𝒜) **all agree** that amplitude gain is non-intrinsic.
Three independent legs collapse to one verdict → not metaphor.
